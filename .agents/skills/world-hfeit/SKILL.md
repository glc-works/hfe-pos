# 🌐 World.Hfeit — Living Commercial Simulator & UI Testbed

`World.Hfeit` (`world.hfeit.com`) adalah ekosistem simulasi bisnis hidup otonom yang menggabungkan:
1. **Interactive Coffee Tycoon Mini-Game & UI Testbed** di browser web.
2. **5-Year Living Business Roleplay Engine** (Storytelling novel & audit horison 5 tahun).
3. **Headless Agent Town & CI Testing Harness** (Simulasi 30 hari / 60 ticks perbankan & akuntansi).

---

## 🚀 Panduan Memulai Cepat (Quickstart Commands)

### 1. 🎮 Menjalankan Mini-Game & Living UI Testbed di Web
```bash
npm run dev
```
Buka browser di **`http://localhost:5173`**, lalu klik menu **`"🎮 World.Hfeit"`**.

### 2. 🎭 Menjalankan Simulasi Roleplay 5 Tahun di Terminal
```bash
python3 scripts/roleplay-runner.py --horizon-years 5 --speed fast
```

### 3. ⚡ 1-Click Interactive Menu Launcher
```bash
./scripts/start.sh
```
